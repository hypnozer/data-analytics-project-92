# Дашборд «Продажи: продавцы и покупатели»

[Открыть дашборд в Preset](https://840087cf.us1a.app.preset.io/superset/dashboard/8/)

Шаг 8 выполнен: импортированы все шесть CSV шагов 6 и 7, сохранены семь представлений. Дашборд опубликован в рабочем пространстве Preset; для просмотра требуется доступ к нему.

Период продаж: сентябрь — декабрь 1992 года. Выручка = цена товара × количество. Денежные результаты округлены вниз; валюта в исходных данных не указана.

## Проверка и трактовка

- Все семь представлений отображаются без ошибок запросов.
- Возрастные группы: 2663 + 5139 + 11957 = 19759 покупателей.
- Уникальные покупатели по месяцам: 226, 230, 228, 229. Эти показатели нельзя складывать для получения уникального числа за весь период.
- В CSV одна строка на месяц или продавца. SUM в соответствующем графике сохраняет исходное значение; SUM(average_income) не является суммированием средних разных продавцов. MAX в движке File Uploads вызывал ошибку преобразования, поэтому заменён на SUM.
- Общая средняя выручка за сделку: 267165.8761576. Отбор продавцов ниже средней выполнен до округления.
- Топ-10 и список продавцов ниже средней — ограниченные выборки, их показатели не являются итогами по всем продавцам.
- Акционным считается товар с нулевой ценой. Первая покупка определяется среди всех продаж по sale_date и sales_id при совпадении дат.
